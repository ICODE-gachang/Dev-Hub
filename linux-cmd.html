🍓 라즈베리파이 & 하드웨어 제어
핀 상태 확인 (pinout)
라즈베리파이 헤더의 GPIO 핀 보드 번호와 배치도를 시각적으로 보여줍니다.
pinout
라즈베리파이 메인 설정
I2C, SPI, SSH, 비밀번호, 와이파이 설정 등을 구성하는 GUI 메뉴입니다.
sudo raspi-config
I2C 센서 주소 스캔
연결된 I2C 센서들의 하드웨어 헥사 주소(예: 0x27)를 탐색합니다.
sudo i2cdetect -y 1
CPU 온도 확인
라즈베리파이 CPU의 실시간 온도를 섭씨(°C) 단위로 출력합니다.
vcgencmd measure_temp
전압 부족 및 스로틀링 상태 확인
어댑터 전압 부족 경고(Under-voltage) 이력을 점검합니다. (0x0이면 정상)
vcgencmd get_throttled
📂 파일 & 디렉토리 탐색/조작
현재 위치 확인 (pwd)
현재 작업 중인 디렉토리의 절대 경로를 표시합니다.
pwd
숨김파일 포함 상세 목록 (ls)
권한, 소유자, 파일 용량, 수정 날짜 및 숨김 파일(.으로 시작)을 모두 출력합니다.
ls -la
디렉토리 이동 (cd)
원하는 디렉토리로 이동하거나 상위 디렉토리(..)로 이동합니다.
cd /path/to/folder
하위 폴더까지 한 번에 생성 (mkdir)
경로상의 모든 하위 폴더를 자동으로 함께 만듭니다.
mkdir -p parent/child/folder
강제 전체 삭제 (rm)
폴더와 하위 모든 파일을 확인 절차 없이 즉시 강제 삭제합니다. (주의!)
rm -rf 폴더/파일이름
실행 권한 부여 (chmod)
파이썬 또는 쉘 스크립트 파일에 직접 실행 권한(+x)을 부여합니다.
chmod +x script.py
🌐 네트워크 & 통신
내 IP 주소 빠르게 확인
라즈베리파이에 할당된 무선(wlan0) 및 유선(eth0) IP 주소를 확인합니다.
hostname -I
SSH 원격 접속하기
PC 터미널에서 라즈베리파이로 보안 원격 세션을 연결합니다.
ssh pi@192.168.0.X
네트워크 연결 상태 체크 (Ping)
외부 서버와의 인터넷 연결 상태를 패킷 송수신으로 테스트합니다.
ping -c 4 google.com
⚙️ 시스템 관리 & 파이썬
OS 시스템 패키지 업데이트
패키지 목록 최신화 후 설치된 프로그램을 최신 버전으로 올립니다.
sudo apt update && sudo apt upgrade -y
파이썬 가상환경 생성 및 활성화
프로젝트별 독립된 파이썬 라이브러리 가상환경(venv)을 구축합니다.
python3 -m venv venv && source venv/bin/activate
실시간 리소스 및 프로세스 모니터링
CPU, 메모리 사용량 및 동작 중인 프로세스를 모니터링합니다.
htop
안전한 시스템 재부팅
라즈베리파이 시스템을 재부팅합니다.
sudo reboot
